# Jesko-23 个人履历网站 · v3 卡通版内容与风格锁定

## 用户本轮明确调整

- 新建 Git 分支完成整版卡通方案，不修改或推送 `main`。
- 头像改为温暖、亲和、原创的欧美电影动画感角色，不使用赛博朋克、霓虹边光或暗黑机甲服装。
- 全部 section 采用同一个动画作品集世界，而不是只替换头像。
- 继续保留：小头像、文字 + 图标架构、四阶段履历、丰富但流畅的交互和渐变动效、轻量图片加载。

## 视觉方向：Animated Product Story / 动画产品叙事

- Palette：Canvas `#FFF9F1`、Ink Navy `#17233C`、Story Blue `#3B82F6`、Sky `#BFE3FF`、Coral `#FF7A66`、Butter `#FFD86B`、Mint `#A8E6CF`。
- Typography：具有动画标题卡气质的圆润 display sans + 清晰中文 sans + mono utility。标题有角色感，正文保持职业与易读。
- Portrait：原创西方电影动画角色；保留卷发、青年脸型、眉眼和安静气质；半身小头像，智能休闲穿搭；不做现有 Disney 角色复刻。
- Layout：大留白、柔和圆角、局部全出血色块、storyboard 式段落；能力、项目和履历像一段逐镜展开的职业故事。
- Signature：一条手绘感“idea trail”从 Hero 的业务问题开始，穿过三个能力，在项目中变成流程，在履历中变成成长路径。
- Motion：漂浮的纸片 / 星点 / 圆角色块，轻量视差，渐变色域缓慢移动，卡片有弹性但克制的 hover；支持 reduced motion。
- Avoid：赛博朋克、黑底霓虹、3D 玩具头、幼儿化 Q 版、巨幅人物、模板化 bento、假 KPI、Emoji 图标、过多糖果色。

## 内容与真实性边界

内容、项目和证据沿用 v2 已确认事实；架构仍必须 code-native；大职业照和架构 PNG 不进入页面运行时；量化项目不承诺收益；没有脱敏产品截图时继续明确标记 replace-later。
