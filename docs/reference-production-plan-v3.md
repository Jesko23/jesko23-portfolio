# v3 卡通版参考图生成计划

## STYLE_FINGERPRINT

- `#FFF9F1` warm canvas, `#17233C` ink, `#3B82F6` story blue, `#BFE3FF` sky, `#FF7A66` coral, `#FFD86B` butter, `#A8E6CF` mint.
- Rounded editorial display + clean Chinese sans + compact mono labels.
- Soft 20—28px corner system, 2px ink outlines, restrained paper-like shadows, hand-drawn line accents.
- One original Western feature-animation portrait style across all references.
- One idea-trail motif; no cyber glow, dark technical grid, fake dashboard or candy overload.

## 审查要求

- 参考图看起来像现代欧美个人作品集网页，而不是动画海报、儿童学习页或品牌 landing 模板。
- 同一头像、色板、线条、阴影与 idea-trail 贯穿全站。
- 每个 section 保留一个主焦点，最多两个辅助 anchor；移动端可自然 restack。
- 只显示已确认内容，不生成新的公司、地点、指标、社交链接或履历事实。
