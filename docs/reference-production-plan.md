## Responsive implementation contract

- Breakpoints：桌面 `>= 1200px`；平板 `768–1199px`；移动端 `< 768px`。所有正文保持可读字号，不允许把 16:9 参考图整体等比缩小。
- Navigation：桌面保留四项导航；移动端折叠为菜单按钮，打开后为全宽纵向链接；active state 始终使用 cobalt 文字 + 单一小圆点。
- Hero：桌面左右图文；移动端按“身份 -> CURRENT/TARGET -> 定位 -> CTA -> 肖像 -> metadata”单列排列，肖像使用独立裁切，不与文字重叠。
- Capabilities：桌面三列；移动端按固定顺序拆为三个纵向段落，每段保留标题、说明和两条证据，项目证明变为两条可点击项目链接。
- 黑豆跨境集群：桌面 `采购 -> 库存 -> 物流 ->（FBA / 海外仓）`；移动端主干纵排，物流后出现两个同级分支；贡献、技术证据和产品工作台依次单列，工作台允许全屏查看。
- HeidouAI 量化：桌面流程与贡献左右分栏；移动端按简介、贡献、五层流程、来源图、免责声明排序；五层流程纵排，来源图提供明确的放大/全屏入口。
- Timeline：桌面横向；移动端改为纵向时间轴并在 `NOW` 结束，`CURRENT` 与 `TARGET` 分行；联系入口改为纵向链接，每个点击区至少 44px 高。
- Touch and accessibility：交互元素最小点击区 44px；正文与背景满足 WCAG AA 对比度；动画遵循 `prefers-reduced-motion`；图片提供 alt，键盘可访问所有导航、项目入口与放大控件。
